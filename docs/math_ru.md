# Математика в NawOS

Эта часть NawOS теперь работает через комплексные числа.

Идея простая:
- обычное `2 + 2` в калькуляторе считается как `(2 + 0i) + (2 + 0i)`
- можно вводить явные комплексные числа вроде `(2 + 2i)`
- квадратные уравнения принимают коэффициенты `a`, `b`, `c` как обычные или комплексные выражения
- в Lelya добавлен math API для прямого вызова из языка

## 1. Калькулятор `calc`

### Базовый синтаксис

```text
calc <выражение>
calc expr <выражение>
calc quad <a> <b> <c>
```

Если вызвать `calc` без аргументов или `calc help`, покажется краткая подсказка.

### Что понимает выражение

Поддерживаются:
- числа: `2`, `3.14`, `1e-3`
- мнимая единица: `i`
- комплексные литералы: `2i`, `(2 + 2i)`, `-i`
- константы: `pi`, `e`
- скобки
- унарные `+` и `-`
- операции `+`, `-`, `*`, `/`, `^`
- функции `sqrt`, `sin`, `cos`, `tan`, `exp`, `log`, `pow`, `abs`, `arg`, `conj`, `norm`, `re`, `im`

### Примеры

```text
calc 2+2
calc (2+2i) + (2+3i)
calc sqrt(-1)
calc pow((1+i), 2)
calc exp(i * pi) + 1
calc log(e)
calc abs(3+4i)
calc arg(1+i)
calc re(2+5i)
calc im(2+5i)
```

### Что возвращается

`calc` печатает результат в комплексной форме:

```text
(4.0000 + 0.0000i)
(4.0000 + 5.0000i)
(0.0000 + 1.0000i)
```

Даже если ответ вещественный, он всё равно выводится как комплексное число.

### Квадратные уравнения

Команда:

```text
calc quad <a> <b> <c>
```

Коэффициенты можно писать:
- просто числами: `1`, `-3`, `2`
- комплексными выражениями: `(2+2i)`, `(3-i)`, `4`

Можно разделять аргументы пробелами или запятыми. Если внутри коэффициента есть пробелы, лучше оборачивать его в скобки.

Примеры:

```text
calc quad 1 -3 2
calc quad 1 0 1
calc quad (2+2i) (3-i) 4
calc quad (2 + 2i), (3 - i), 4
```

Случаи вывода:
- обычное квадратное уравнение -> `x1` и `x2`
- вырожденное линейное -> `Linear solution: x = ...`
- бесконечно много решений -> `Quadratic equation has infinitely many solutions.`
- нет решения -> `Quadratic equation has no solution.`

### Небольшие замечания

- `calc` умеет вычислять выражения напрямую, так что `calc 2+2i + 2+3i` работает без `expr`
- если хочешь явно вызвать именно калькуляторный парсер, можно писать `calc expr ...`
- `re` и `im` в `calc` возвращают значение в комплексной форме с нулевой мнимой частью

## 2. Lelya math API

В языке добавлены native-вызовы для математики. Результат этих вызовов обычно печатается через `print`.

### Важное ограничение

Сейчас math API предназначен для вычисления и вывода результата.

- математический результат возвращается как текст
- обычные переменные языка остаются целочисленными
- если нужно посчитать комплексное выражение внутри языка, используй `print math_eval(...)` или другой `math_*`
- вложенные `math_*` внутри аргументов не нужны и не являются основным сценарием использования

### Доступные функции

```text
math_eval(expr)
math_add(a, b)
math_sub(a, b)
math_mul(a, b)
math_div(a, b)
math_pow(a, b)
math_sqrt(x)
math_sin(x)
math_cos(x)
math_tan(x)
math_abs(x)
math_arg(x)
math_conj(x)
math_norm(x)
math_quad(a, b, c)
```

### Как передавать аргументы

Аргументы пишутся как raw math expressions, то есть без кавычек.

Правильно:

```text
print math_add(2+2i, 2+3i)
print math_sqrt(-1)
```

Неправильно:

```text
print math_add("2+2i", "2+3i")
```

Если выражение сложное, оборачивай его в скобки:

```text
print math_add((2 + 2i), (2 + 3i))
print math_pow((1 + i), 2)
```

### Примеры

```text
print math_eval(2+2)
print math_eval((2+2i) + (2+3i))
print math_add(2+2i, 2+3i)
print math_sub(2+3i, 1+i)
print math_mul(1+i, 1-i)
print math_div(1+i, 2)
print math_pow(1+i, 2)
print math_sqrt(-1)
print math_sin(pi / 2)
print math_cos(pi)
print math_tan(pi / 4)
print math_abs(3+4i)
print math_arg(1+i)
print math_conj(2+3i)
print math_norm(3+4i)
print math_quad(1, -3, 2)
```

### Вывод

- `math_eval`, `math_add`, `math_sub`, `math_mul`, `math_div`, `math_pow`, `math_sqrt`, `math_sin`, `math_cos`, `math_tan`, `math_conj`, `math_norm`, `math_quad` возвращают текст в комплексной форме
- `math_abs` и `math_arg` возвращают обычное вещественное значение как текст
- `math_quad` возвращает многострочный текст с корнями или текст ошибки

### Примеры результата

```text
print math_add(2+2i, 2+3i)
```

Ожидаемый вывод:

```text
(4.0000 + 5.0000i)
```

```text
print math_quad(1, -3, 2)
```

Ожидаемый вывод:

```text
x1 = (2.0000 + 0.0000i)
x2 = (1.0000 + 0.0000i)
```

### Про `exp`, `log`, `re`, `im`

В калькуляторе они доступны напрямую.

В NawLang отдельные native-обёртки для них не добавлялись, но при необходимости можно использовать `math_eval(...)` с тем же математическим синтаксисом:

```text
print math_eval(exp(i * pi) + 1)
print math_eval(log(e))
print math_eval(re(2+5i))
print math_eval(im(2+5i))
```

## 3. Короткий набор примеров

### В калькуляторе

```text
calc (2+2i) + (2+3i)
calc sqrt(-1)
calc quad 1 -3 2
```

### В NawLang

```text
print math_add(2+2i, 2+3i)
print math_sqrt(-1)
print math_quad(1, -3, 2)
```

## 4. Практическая подсказка

Если надо просто быстро посчитать что-то в комплексной форме, используй `calc`.

Если надо встроить вычисление в программу на Lelya, используй `print math_*`.
